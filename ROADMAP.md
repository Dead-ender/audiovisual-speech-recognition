# Roadmap

This roadmap lists possible next steps; none of these are claimed as completed results.

- Add a reproducible real-corpus experiment with documented permission, speaker-disjoint splits, and a published evaluation protocol.
- Add media-level integration tests using generated, redistributable audio/video fixtures.
- Add optional mouth-region detection/tracking and explicit audio/video synchronization tools.
- Compare greedy decoding with prefix beam search and language-model-assisted decoding.
- Add augmentation and ablation experiments, with configs and logged seeds.
- Explore longer-utterance encoders that do not require full quadratic self-attention.
