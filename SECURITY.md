# Security and privacy

This repository processes speech and face video, which can contain identifying biometric information. Do not open a public issue with recordings, transcripts tied to a person, private paths, access tokens, or checkpoints derived from private data.

For a security-sensitive code issue, use GitHub's private vulnerability reporting for this repository if it is enabled. Otherwise, contact the repository owner through GitHub before sharing technical details publicly.

The repository does not provide clinical, identity, or surveillance guidance. Users are responsible for consent, data access, retention, and dataset-license requirements.
